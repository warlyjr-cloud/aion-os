# Code of Conduct

## Our standards
- Be respectful. Critique the code, not the person.
- Ad hominem attacks, harassment, or toxic behavior are not tolerated
  and can result in a ban from the repository.
- Back architectural claims with evidence (a test, a real command's
  output, a reproducible run) rather than assertion — see
  `docs/PROJECT_STATUS.md` for what "proven" means in this project.

## Reporting
Report violations by opening a private security advisory on this
repository, or contacting the maintainer directly.
